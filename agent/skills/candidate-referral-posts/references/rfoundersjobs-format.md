# rfoundersjobs Format Reference

## Channel context
- Telegram: `@rfoundersjobs` — job board for the R-Founders community
- Posts written FROM the recommender's perspective (a founder/colleague posting about a candidate)
- Language primarily Russian, but English is accepted (especially for non-Russian-speaking recommenders)
- Post IDs referenced: #417, #422, #424

## Standard structure

### 1. Header
```
#кандидат <Role Title(s)>
```
Example: `#кандидат Chief Creative Officer, Senior Writer`

### 2. Recommender attribution
```
Recommended by <Name>, [role] в [Company]:

<Candidate Name>
```
Or in Russian:
```
Рекомендует <Name>, [role] и founder [Company]:

<word from recommender about candidate — can be a blockquote>
```

### 3. Key achievements section
Bullet points with specific, measurable achievements:
```
• ex-<company>, <years> managed <function> in B2B (growth x5) and B2C (growth x3,5)
• in role of <X> organized <Y> for <Z>
• managed <KPI> with results $100-600K
• built <system> from scratch
```

### 4. Recommender's personal quote (blockquote)
A direct quote from the recommender in blockquote format:
```
> "What I personally appreciated about <Name>: <specific quality>, <ability to X>, <team behaviour>, <result>."
```

### 5. Skills section (optional, sometimes included in bullet points)
```
Skills:
• <technology/domain>
• <technology/domain>
```

### 6. What the candidate is looking for
```
🦒 Successfully built <notable achievement> for <company>:
<url>

LinkedIn → <link>.
Contact → <link>.
CV attached.
```

### 7. Call to action + channel tag
```
Write to this awesome person soon! And send us hearts and fires — standard here :)

@rfoundersjobs
```

## Key formatting rules

1. **Bullet points** are the standard — not paragraphs
2. **Company names** are hyperlinked inline (when possible)
3. **Hashtag `#кандидат`** always at the top
4. **Recommender attribution** is prominent at the start — establishes credibility
5. **Blockquote** for the recommender's personal words (warmth + authenticity)
6. **Links section** at the bottom: LinkedIn, contact, CV
7. **Emoji reactions** on the post: 🔥❤️🦄👍 are common
8. **Channel tag** `@rfoundersjobs` at the very end

## English adaptation (for non-Russian-speaking recommenders)

When the recommender doesn't speak Russian, adapt:

| Russian element | English equivalent |
|---|---|
| `#кандидат` | Keep `#candidate` |
| `Рекомендует <Name>` | `Recommended by <Name>` |
| Blockquote with recommender's words | Same, in English |
| `Тут` (link placeholder) | Link directly or use `→` |
| `Пишите скорее!` | Omit or replace with shorter CTA |
